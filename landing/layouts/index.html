01 / THE WORKFLOW

From URL to answer,
without leaving the window.

Move from browsing to request debugging in one compact workspace.

01

Open

Visit an HTTP, HTTPS, or local file URL. Follow extracted links and keep several pages in tabs.

02

Adjust

Set method, headers, body, auth, cookies, proxy, redirects, and TLS options in the request drawer.

03

Inspect

Switch among rendered text, response source, headers, and the exact request you sent.

04

Keep

Save request templates, export a response, or copy a best-effort curl command or Python snippet.

02 / USEFUL DETAILS

Room to explore.
Enough control to learn.

⌘

Request control

Try custom methods and bodies, choose proxy and auth settings, and preview the request before it goes out.

▣

Response views

Read HTML as text, inspect the raw source, and examine headers without switching tools.

◇

Local memory

Keep browsing history, bookmarks, saved requests, preferences, and a cookie jar on your machine.

What it is: a text-first desktop client. What it does not do: execute JavaScript, render a full browser DOM, or provide headless automation.
